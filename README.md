# ZerbitzariTxikiBat

Basic Node.js server built with Express for introductory REST API practice.

## What it covers

- simple HTTP routes
- in-memory user data
- request testing from an IDE HTTP client
- Express routing and middleware basics

## Architecture

The Express application maps HTTP routes to handlers over an in-memory collection. There is no database adapter, so state belongs to the running process and is reset whenever the server restarts.
